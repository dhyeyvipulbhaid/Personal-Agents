# M6 approvals check

Open Personal Agents and choose Approvals.

A waiting request shows Approve, Deny, Provide more info, Edit, and Snooze, plus Once and For this task. Approving resumes the paused task. Another task keeps running while one is paused. A more-info reply becomes the task's next instruction. An edited draft is what runs. A snoozed request comes back at its time. A config change that fails to start is rolled back. Each of those steps is in the audit log. The scripted cases run in CI. On a device, confirm the buttons are on the page and a decision shows on Activity.
