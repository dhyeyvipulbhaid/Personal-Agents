# M11 memory page

The Memory page and chat share one bank. Save a fact on the page. It appears in the list, labeled with the chat agent. Delete it. The list no longer shows it, and a later chat does not use it.

Filter the list, edit a fact, select several and delete them, and run Preview junk before Delete junk. Reflect now writes derived observations that cite facts. The graph can be paused, filtered by edge type, panned, and clicked. Settings on this page saves the embedding model and can leave derived observations out of chat. Encrypt memory at rest is off until that checkbox is turned on. The key stays in the macOS Keychain or Windows Credential Manager.

Chat's automatic save, after a reply finishes, is the M18 check. The page checks above run in CI.
