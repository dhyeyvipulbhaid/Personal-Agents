# M8 chat check

Run this on device A and again on device B, with Ollama running.

1. Press Alt+C from Home, Activity, or Approvals. Chat opens.
2. Send a message. The reply streams from the chat model. Write down the first-token time for this device.
3. Change the chat model and send another message. The next reply uses the new model.
4. When a reply asks for approval, the request is in the thread and on Approvals. Approving it in the thread removes it from Approvals.
