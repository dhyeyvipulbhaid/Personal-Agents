# G1 locked-down gate

Run the M4 installer on device C, a machine with the strict IT controls you care about. Record the result either way.

- If Personal Agents installs and launches, write that down.
- If it stops, write the message and name what blocked it. Examples: SmartScreen, AppLocker, Gatekeeper, or Santa.

If unsigned code is blocked, the signing work starts. Do not bypass the block to force a pass.
